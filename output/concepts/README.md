# Original Nestle characters — concept v1

## Purpose
Visual approval of a fully original modular human avatar system. Generated concept artwork is not a rigged or usable 3D model. The existing Quaternius browser preview is unchanged.

## Design requirements
- Cozy villager proportions: large rounded head, small torso, short legs, round shoes, mitten-like hands, simple expressive eyes.
- Consistent front, true side, and three-quarter views of one base.
- Six hairstyles: soft crop, side-swept, bob, long fringe, curly puff, and low ponytail.
- Five natural skin tones and four outfits: hoodie, T-shirt with trousers, sweater, and casual dress.
- Happy, sad, sleepy, surprised, and affectionate expressions.
- Idle, walk, wave, sit, dance, and two-person hug pose studies.
- Identical furnished shared-room concepts in pink daylight and dark evening lighting.
- All customization choices use one base without gender restrictions.

## After visual approval
Create original editable Blender source, a shared character rig, interchangeable hair and clothing meshes, facial expression controls, and mobile-ready GLB exports. Test clip playback, clothing clipping, silhouette readability at app scale, and device performance before replacing the temporary preview characters.

## Concept limitations
The sheet establishes visual intent. Generated turnarounds and clothing require a 3D artist's construction pass for exact orthographic alignment, topology, hidden surfaces, skinning, and deformation. Pose drawings are not animation clips. Lighting studies do not implement the native app.

## Provenance
Artwork generated with the built-in image generation tool. The exact generation prompt is stored alongside the selected image. Existing game characters and Quaternius geometry are not used as inputs for this original sheet.
