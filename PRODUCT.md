# Nestle

## Platform
The planned product is an iOS and Android couples app. The workspace contains a local web preview of temporary avatar assets and a separate original-character concept deliverable.

## Users and purpose
Two partners share a miniature home with customizable characters. The user approved the original cozy villager concept and authorized a fully original, gender-unrestricted modular character base, rig, facial expressions, GLB/Blender exports, and preview integration.

## Stack
Plain HTML/CSS and JavaScript with Three.js. A local Node server serves bundled assets. No backend or external accounts.

## Confirmed constraints
Preserve the pink and dark themes from the supplied Nestle PDF. Original characters use rounded heads, small bodies, simple expressive faces, soft colors, and mitten-like hands. The current Quaternius preview stays available until original models are approved and ready; its models are temporary, not the final character direction. No live location, chat, or AI is connected.

## Assets
Source: Ultimate Modular Men- Feb 2022-20261020T112647Z-1-001.zip. glTF files and original License.txt are in public/assets/characters. The included license states CC0 1.0.

The approved concept remains under output/concepts. Original authoring source is scripts/build-original-avatars.py. Editable model source goes in output/models, and runtime GLB/manifest files in public/assets/original. The earlier asset preview is preserved at /quaternius.html. The first original modeling pass requires visual review and physical-phone performance validation before production use.
